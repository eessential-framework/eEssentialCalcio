# eEssential Web

Sito statico responsive derivato dal PDF eEssential_Brochure_Calcio.pdf.

## Pubblicazione
Caricare sul web server l'intera cartella mantenendo la struttura:
- index.html
- styles.css
- script.js
- assets/

Non sono richiesti database, PHP o Node.js.

Le immagini provengono dal materiale della brochure; i contenuti testuali sono basati sul PDF fornito.
